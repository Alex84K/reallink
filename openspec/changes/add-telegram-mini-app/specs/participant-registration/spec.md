# Spec Delta

## MODIFIED Requirements

### Requirement: Формат Telegram username
Система SHALL принимать Telegram username длиной 5–32 символа из латинских букв, цифр и подчёркивания, с `@` или без него, и хранить его без `@`. Второй активный участник с тем же username (без учёта регистра) MUST NOT создаваться. При входе через Telegram Mini App username берётся из Telegram и вручную не вводится.

#### Scenario: Username с символом @
- **WHEN** посетитель вводит `@Anna_Walks`
- **THEN** система сохраняет `Anna_Walks`

#### Scenario: Повторная регистрация
- **WHEN** анкета приходит с username, который уже есть у активного участника
- **THEN** анкета отклоняется с предложением войти через Telegram или восстановить ссылку через администратора

### Requirement: Язык интерфейса
Система SHALL показывать интерфейс участника на ru, uk, ro или de. По умолчанию — язык Telegram (в Mini App) или браузера, если он среди поддерживаемых, иначе немецкий. Участник SHALL иметь возможность переключить язык; выбор сохраняется в профиле и используется для уведомлений.

#### Scenario: Браузер на румынском
- **WHEN** посетитель с языком браузера `ro-RO` открывает анкету
- **THEN** анкета показывается на румынском

#### Scenario: Telegram на украинском
- **WHEN** пользователь с языком Telegram `uk` впервые открывает Mini App
- **THEN** анкета показывается на украинском

#### Scenario: Переключение языка
- **WHEN** участник переключает язык на украинский
- **THEN** интерфейс показывается на украинском, введённые данные сохраняются

### Requirement: Удаление данных участника
Участник SHALL иметь возможность удалить свои данные на своей странице; администратор SHALL иметь возможность сделать это по запросу. Персональные данные (имя, Telegram username и ID, «о себе») MUST удаляться безвозвратно; для статистики остаются обезличенные записи.

#### Scenario: Удаление по ссылке
- **WHEN** участник подтверждает удаление
- **THEN** персональные данные удаляются, доступ по ссылке и через Telegram прекращается, активные предложения отменяются

#### Scenario: Статистика после удаления
- **WHEN** удалён участник, который ранее встретился с партнёром
- **THEN** встреча продолжает учитываться в статистике без персональных данных

### Requirement: Источник регистрации
Система SHALL сохранять у участника канал регистрации (веб или Telegram) и источник: из параметра `src` в ссылке на анкету или из параметра запуска Mini App, чтобы owner видел результат каналов привлечения.

#### Scenario: Переход из диаспорного чата
- **WHEN** посетитель открывает анкету по ссылке с `src=tg-romani-hannover` и отправляет её
- **THEN** у участника сохраняются источник `tg-romani-hannover` и канал `web`

#### Scenario: Запуск Mini App со ссылки
- **WHEN** пользователь открывает Mini App по ссылке с параметром запуска `ig-ukr-hannover` и регистрируется
- **THEN** у участника сохраняются источник `ig-ukr-hannover` и канал `telegram`

#### Scenario: Без источника
- **WHEN** посетитель пришёл по ссылке без `src`
- **THEN** источник сохраняется как `direct`
