# Spec Delta

## ADDED Requirements

### Requirement: Разрез по каналу регистрации
Система SHALL показывать число участников и состоявшихся встреч по каналу регистрации (веб, Telegram).

#### Scenario: Сравнение каналов
- **WHEN** администратор выбирает разрез «канал»
- **THEN** видно, сколько участников пришло через веб и сколько через Mini App, и сколько из них встретились
