# Spec Delta

## Purpose

Показывает owner и администратору простую статистику продукта: сколько людей зарегистрировалось, из каких источников, сколько пар и состоявшихся встреч. Это нужно, чтобы видеть результат привлечения и главную метрику Real Connections.

## ADDED Requirements

### Requirement: Сводка
Система SHALL показывать администратору за выбранный период (по умолчанию — всё время): число участников по статусам, созданных пар, принятых пар, состоявшихся встреч (Real Connections), позитивных фидбеков (оценка «супер» или «нормально») и жалоб.

#### Scenario: Открытие статистики
- **WHEN** администратор открывает раздел «Статистика»
- **THEN** он видит сводку за всё время с числом состоявшихся встреч на первом месте

#### Scenario: Пустой период
- **WHEN** за выбранный период нет данных
- **THEN** счётчики показывают 0 без ошибок

### Requirement: Динамика по неделям
Система SHALL показывать те же счётчики по календарным неделям (понедельник–воскресенье, Europe/Berlin).

#### Scenario: Недельная таблица
- **WHEN** администратор выбирает вид «по неделям»
- **THEN** каждая строка — неделя с новыми участниками, парами и встречами

### Requirement: Разрезы
Система SHALL показывать число участников и состоявшихся встреч по источнику регистрации (`src`), сценарию (Language, Home) и родному языку (ru, uk, ro, de).

#### Scenario: Результат канала привлечения
- **WHEN** owner запустил рекламу со ссылкой `src=fb-romani-hannover`
- **THEN** в разрезе по источнику видно, сколько участников пришло по этой ссылке и сколько из них встретились

### Requirement: Экспорт
Администратор SHALL иметь возможность выгрузить обезличенные данные по участникам, парам и встречам в CSV. Имена, Telegram username и ID MUST NOT попадать в выгрузку.

#### Scenario: Экспорт CSV
- **WHEN** администратор нажимает «Экспорт CSV»
- **THEN** скачивается файл со статусами, датами, сценариями, источниками и фидбеком без персональных данных
