# Инструкции для AI-агентов

- Поведение системы — в `openspec/`. Изменение поведения начинается с change (`/opsx:propose`), код пишется по `tasks.md` (`/opsx:apply`). Артефакты OpenSpec — на русском, заголовки и SHALL/MUST/WHEN/THEN — на английском.
- Contract-first: изменение API начинается с `api/openapi.yaml`, затем `make gen`. Сгенерированный код не читать и не править.
- У каждой части свои правила, они подгружаются при работе в папке: `server/CLAUDE.md`, `frontend/CLAUDE.md`, `adminpanel/CLAUDE.md`.
- Работай в границах задачи: одна группа tasks.md — одна папка (срез сервера или фича фронтенда). Для широкого поиска по репозиторию используй субагента Explore.
- Персональные данные (имя, Telegram, «о себе», токены) не попадают в логи, журнал аудита и экспорт.
- Время хранится в UTC, показывается в Europe/Berlin.
