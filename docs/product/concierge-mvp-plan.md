# 🧪 Real Connections — Concierge MVP Plan

## Цель

Проверить 4 ключевые гипотезы **за 6 недель**, **без приложения**, **бюджет ~€200**.

---

## 1. Гипотезы для проверки

| # | Гипотеза | Как проверяем | Порог успеха |
|---|----------|--------------|--------------|
| H1 | Люди готовы заполнить анкету о себе для подбора | Кол-во заполненных анкет | ≥ 40 из 100 увидевших |
| H2 | Люди доверяют рекомендации и соглашаются на встречу | % согласившихся из получивших пару | ≥ 50% |
| H3 | Встречи реально происходят | % пар, которые встретились | ≥ 40% |
| H4 | Люди хотят повторить опыт | Запрос на новый матч после первой встречи | ≥ 30% |

> **Важно:**
> Если H1 провалена — проблема не настолько болит.
> Если H2 провалена — формат подбора не работает.
> Если H3 провалена — барьер оффлайна слишком высок.
> Если H4 провалена — продукт "одноразовый".

## 3. Сценарий — один фокус

### Выбранный сценарий: Языковая прогулка 🚶‍♂️🗣

Почему именно это:
- Самый низкий барьер входа (бесплатно, публичное место, ограничено по времени)
- Понятная ценность (практика языка + прогулка + знакомство)
- Легко объяснить в одном предложении
- Целевая аудитория чётко определена

**Одно предложение:**

> «Мы подберём тебе собеседника для языковой прогулки в Ганновере — русский ↔ немецкий, 45 минут, в парке рядом с тобой.»

## 4. Анкета (Google Form)

### Поля:

```
1. Имя (как к тебе обращаться)
2. Возраст (диапазон: 20-25 / 25-30 / 30-35 / 35-40 / 40-45 / 45+)
3. Район Ганновера (выпадающий список)
4. Родной язык (русский / немецкий / другой)
5. Какой язык хочешь практиковать? (русский / немецкий)
6. Уровень языка (начальный / средний / продвинутый)
7. Когда удобно? (будни утро / будни вечер / выходные утро / выходные день)
8. Что тебе интересно? (3-5 тегов: музыка, спорт, природа, технологии,
   кулинария, путешествия, дети/семья, книги, искусство, бизнес)
9. Telegram username
10. Одно предложение о себе (необязательно)
```

> Анкета должна заполняться за **2 минуты максимум**. Каждое лишнее поле = –15% конверсии.

## 5. Процесс матчинга (ручной)

### Алгоритм в голове:

```
Шаг 1: Язык
  Русскоязычный хочет немецкий ↔ Немецкоязычный хочет русский
  (или оба хотят практиковать язык друг друга)

Шаг 2: География
  Живут в пределах ~20 мин друг от друга

Шаг 3: Время
  Есть пересечение по доступности

Шаг 4: Интересы
  ≥ 1 общий тег

Шаг 5: Возраст
  Разница не более ~10 лет (гибко)
```

### Шаблон сообщения паре:

```
Привет, [Имя]! 👋

Мы нашли тебе собеседника для языковой прогулки:

🙂 [Имя партнёра], [возраст-диапазон]
🗣 Говорит: [язык], хочет практиковать: [язык]
📍 Район: [район]
💡 Интересы: [общие теги]

Предлагаем встретиться:
📅 [день], ~[время]
📍 [парк/место] — скамейка у входа

Формат: прогулка 45 минут, переключаетесь
между языками каждые 15 мин.

Подходит? Ответь «да» — и мы дадим контакт партнёра.

Если неудобно время/место — предложи своё, подстроим.
```

## 6. После встречи — фидбек

Через 24 часа после запланированной встречи → короткое сообщение:

```
Привет! Как прошла прогулка? 🚶

1. Встреча состоялась?  (да / нет / перенесли)
2. Как оцениваешь? (🔥 супер / 👍 нормально / 😐 так себе)
3. Хочешь ещё одну пару? (да / пока нет)
4. Одно слово/фраза о впечатлении (необязательно)
```

## 9. Критерии решения после 6 недель

### 🟢 GO — строим приложение

Все 4 условия выполнены:
- ≥ 40 анкет собрано
- ≥ 50% пар согласились встретиться
- ≥ 40% встреч реально произошли
- ≥ 30% хотят повторить

**→ Начинаем проектировать MVP-приложение (Telegram-бот или веб-app)**

### 🟡 PIVOT — меняем формат

Часть метрик ниже порога:
- Мало анкет → проблема позиционирования или канала
- Мало согласий → формат не тот (может, группы лучше?)
- Мало реальных встреч → слишком высокий барьер
- Мало повторов → продукт одноразовый

**→ Выбрать новый формат и повторить 4-недельный цикл**

### 🔴 STOP — идея не работает

- < 20 анкет за 2 недели активного промо
- < 3 реальных встречи за 6 недель
- Негативный фидбек по безопасности

**→ Зафиксировать выводы, не тратить ресурсы на разработку**
