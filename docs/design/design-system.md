# Design System

| | |
|---|---|
| Статус | Черновик v0.2 — цвета и шрифт стандартные Bootstrap 5.3; переопределены только скругления и размеры кнопок |
| Источник | [mockups/onboarding-v1.jpg](mockups/onboarding-v1.jpg) — 12 экранов онбординга и главный экран |
| Реализация | `frontend/src/styles/_variables.scss` (копия в `adminpanel/src/styles/`) |
| Правила вёрстки | [frontend/CONVENTIONS.md](../../frontend/CONVENTIONS.md) |

Этот документ — единственный источник правды о визуальном стиле. Код реализует его через переменные Bootstrap; значения в коде и здесь должны совпадать. Меняем сначала документ, потом `_variables.scss`.

> **Принцип: Bootstrap по умолчанию.** Если цвет или шрифт макета близок к стандартному значению Bootstrap 5.3, берём стандартное и ничего не переопределяем. Своё значение задаём, только если отличие заметно и важно для стиля (сейчас это скругления, §5, и цвета логотипа). Значения из макета ниже приведены для справки: они сняты по пикселям JPEG.

---

## 1. Характер

Светлый, «воздушный» интерфейс: белые экраны, светлый фон за ними, один синий акцент, пастельные иконки в кружках, крупные кнопки на всю ширину внизу экрана. Тон — дружелюбный и спокойный. Mobile first: макет нарисован для телефона (375 pt).

## 2. Цвета — стандартные Bootstrap

Цвета в `_variables.scss` **не переопределяются**. В коде используем только классы и CSS-переменные Bootstrap (`text-primary`, `bg-body-tertiary`, `var(--bs-border-color)`), без своих hex.

| Роль | Класс / переменная Bootstrap | Значение Bootstrap | В макете (справка) |
|------|------------------------------|--------------------|--------------------|
| Основной акцент: кнопки, ссылки, активная вкладка, прогресс, выбранные чекбоксы | `primary` | `#0D6EFD` | `#227CF0` |
| Выбранная строка или чип, бейдж «Предлагаю» | `bg-primary-subtle`, `text-primary-emphasis` | `#CFE2FF` / `#052C65` | `#E4ECFC` |
| Заголовки и основной текст | `text-body` | `#212529` | `#070C1F` |
| Подзаголовки, описания, метаданные («2 ч назад», «Ганновер») | `text-body-secondary` | `rgba(33,37,41,.75)` | `#535762` / `#A1A4A9` |
| Фон экранов и карточек | `bg-body` | `#FFFFFF` | `#FFFFFF` |
| Поле поиска, текстовая область, фон вокруг контента на `md+` | `bg-body-tertiary` | `#F8F9FA` | `#F5F5F7` / `#ECF4FC` |
| Невыбранный чип | `bg-body-secondary` | `#E9ECEF` | `#E4ECF4` |
| Рамки полей, разделители | `border` | `#DEE2E6` | `#E4E4EC` |
| Галочки «Готово», бейдж «Ищу услугу» | `text-success`, `bg-success-subtle`, `text-success-emphasis` | `#198754` / `#D1E7DD` | `#23935F` / `#DCF4E4` |
| Ошибки, удаление, жалоба | `danger` | `#DC3545` | нет в макете |

Правила:
- Для метаданных используем `text-body-secondary`, а **не** `text-body-tertiary`: третичный серый на белом даёт контраст около 3:1, это нечитаемо на солнце.
- Белый текст на `primary` (`#0D6EFD`) — контраст 4.5:1, проходит WCAG AA.
- Самое заметное отличие от макета — фон выбранного элемента: в Bootstrap `#CFE2FF` насыщеннее, чем в макете. Пока оставляем стандартный; если owner захочет ближе к макету — одна переменная `$primary-bg-subtle`.

### 2.1 Цвета логотипа (исключение)

Логотип — картинка (SVG), его цвета не связаны с темой Bootstrap и используются только в нём и в иллюстрациях.

| Фигура | Цвет |
|--------|------|
| Левая | `#4FA8F8` |
| Центральная | `#188868` |
| Правая | `#58B888` |

### 2.2 Пастельные иконки

Иконки в кружках (экран приветствия, списки): фон — `*-subtle`, иконка — основной цвет той же роли.

| Пример | Фон | Иконка |
|--------|-----|--------|
| «Новые знакомства» | `bg-primary-subtle` | `text-primary` |
| «Взаимная помощь» | `bg-warning-subtle` | `text-warning-emphasis` |
| «Общие интересы» | `bg-danger-subtle` | `text-danger` |
| «Полезные контакты» | `bg-success-subtle` | `text-success` |

## 3. Типографика — системный шрифт Bootstrap

Шрифт **не меняем**: стандартный стек Bootstrap (`system-ui, -apple-system, "Segoe UI", Roboto, …`). На iPhone это SF Pro — тот же шрифт, что в макете; на Android — Roboto; на Windows — Segoe UI. Плюсы: ничего не загружаем, нет вопросов GDPR с внешними шрифтами, все нужные символы (ș, ț, ї, ґ, ß) есть в системных шрифтах.

Размеры — стандартные Bootstrap, базовый 16 px (поля ввода не меньше 16 px, иначе iOS зумит страницу).

| Стиль | Класс | Размер | Где в макете |
|-------|-------|--------|--------------|
| Название на экране приветствия | `.display-6.fw-bold` | 40 px | «Gemeinsam» |
| Заголовок экрана | `.h3.fw-bold` | 28 px (24 px на мобильном за счёт RFS) | «Создай аккаунт», «Интересы и хобби» |
| Заголовок блока | `.h5.fw-bold` | 20 px | «Профиль создан!» |
| Заголовок карточки | `.fw-semibold` | 16 px | Заголовок в ленте |
| Основной текст, поля | — | 16 px | Тексты, поля ввода |
| Подписи, метаданные | `.small.text-body-secondary` | 14 px | Подзаголовки, «2 ч назад» |
| Кнопки | `.btn-lg.fw-semibold` | 20 px → переопределяем `$btn-font-size-lg` на 16 px | «Далее», «Начать» |

## 4. Отступы и сетка

- Шкала отступов Bootstrap без изменений: `1` = 4, `2` = 8, `3` = 16, `4` = 24, `5` = 48 px.
- Горизонтальный отступ экрана — 16 px (`px-3`).
- Между полями формы — 12 px (`mb-3` ≈ 16 px допустимо); между блоками — 24 px (`mb-4`); заголовок → подзаголовок — 4 px (`mb-1`); подзаголовок → контент — 16 px (`mb-3`).
- Основная кнопка прижата к низу экрана с отступом 16 px и учётом `env(safe-area-inset-bottom)`.
- На экранах шире `md` контент онбординга — колонка до 480 px по центру (`col-md-8 col-lg-5 mx-auto`) на фоне `bg-body-tertiary`.

## 5. Скругления, рамки, тени

| Что | Значение | Как |
|-----|----------|-----|
| Кнопки, поля, плитки, строки-опции | 12 px | `$border-radius` (переопределено, §8) |
| Чекбоксы, мелкие элементы | 8 px | `$border-radius-sm` (переопределено) |
| Карточки, модальные окна | 16 px | `$border-radius-lg` (переопределено) |
| Чипы, бейджи, прогресс | пилюля | `rounded-pill` |
| Рамки | 1 px, стандартный цвет | `border` |
| Фокус | стандартное кольцо Bootstrap | — |
| Тени | почти нет; карточки — `shadow-sm`, круглая кнопка «Создать» — `shadow` | стандартные классы |

Скругления — единственное заметное визуальное отличие макета от Bootstrap (в Bootstrap 6 px), поэтому их переопределяем.

## 6. Иконки и изображения

- Линейные (outline) иконки, толщина 1.75–2 px, скруглённые концы. Библиотека — **Lucide** (`lucide-react`, ISC). Размеры 20 px в списках и полях, 24 px в таб-баре и шапке.
- Иконки в пастельных кружках (§2.2): кружок 40 px, иконка 20 px.
- Плитки интересов — фото с тёмным градиентом снизу и белой подписью; на этапе MVP можно заменить иконками на `*-subtle` фоне, чтобы не лицензировать фотографии.
- Аватар — круг 40 px (лента), 64 px (профиль); заглушка — `bg-body-tertiary` с иконкой камеры.

| Компонент | Описание | Bootstrap / класс |

| Вторичная кнопка | Белая с рамкой (Google, Apple) | `.btn.btn-outline-secondary.btn-lg.w-100` |

## 8. Bootstrap: переменные

Переопределяем только то, что заметно отличается от стандартного Bootstrap: скругления и размер больших кнопок и полей. Цвета и шрифт — стандартные.

```scss
// frontend/src/styles/_variables.scss — подключается ДО bootstrap
$border-radius:      .75rem;  // 12 px — кнопки, поля, плитки (в Bootstrap 6 px)
$border-radius-sm:   .5rem;   // 8 px
$border-radius-lg:   1rem;    // 16 px — карточки, модальные окна

$btn-font-weight: 600;
$input-btn-padding-y-lg: .75rem;  // высота кнопок и полей .lg — 48 px
$input-btn-font-size-lg: 1rem;    // текст 16 px, как в макете
$progress-height: .25rem;         // тонкая полоса прогресса шагов
```

## 9. Открытые вопросы

1. Есть ли исходник макета (Figma)? Тогда сверяем, не отличаются ли какие-то цвета от Bootstrap заметнее, чем видно по JPEG.
2. Название в макете — **Gemeinsam**, в документах — Real Connections / reallink. Какое имя и логотип в продукте?
3. Устраивает ли owner стандартный фон выбранного элемента Bootstrap (`#CFE2FF`), или нужен светлее, как в макете?
4. Тёмная тема — нужна ли на этапе 1? (Сейчас не планируется; переменные Bootstrap 5.3 позволяют добавить её позже.)
